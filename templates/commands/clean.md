Use the Bash tool to clean up orphaned Claude processes and E2E test artifacts. Execute the following commands immediately:

pgrep -f "claude" | while read pid; do ppid=$(ps -o ppid= -p $pid 2>/dev/null | tr -d " "); if [[ "$ppid" == "1" ]]; then echo "Killing: PID $pid"; kill $pid 2>/dev/null; fi; done && echo "Claude orphan process cleanup complete"

Then kill stale playwright-mcp processes older than 6h (forgotten sessions in other terminals), but protect the current session's own MCP children — killing those would disconnect this very session's playwright. First walk up from this shell to the highest "claude" ancestor and exclude its descendants from the age-based kill. Don't lower the 6h threshold — long e2e loops in other terminals may be active:

SELF_CLAUDE=""; _p=$$; while [ -n "$_p" ] && [ "$_p" != "1" ]; do ps -o args= -p "$_p" 2>/dev/null | grep -q "claude" && SELF_CLAUDE="$_p"; _p=$(ps -o ppid= -p "$_p" 2>/dev/null | tr -d ' '); done; PROTECTED=" "; if [ -n "$SELF_CLAUDE" ]; then _q="$SELF_CLAUDE"; while [ -n "$_q" ]; do _n=""; for _x in $(echo "$_q"); do PROTECTED="$PROTECTED$_x "; _n="$_n $(pgrep -P "$_x" 2>/dev/null | tr '\n' ' ')"; done; _q="$(echo $_n | tr -s ' ')"; done; fi; ps -eo pid,etime,args | grep "playwright-mcp" | grep -v grep | awk '{n=split($2,t,/[-:]/); s=(n==4)?t[1]*86400+t[2]*3600+t[3]*60+t[4]:(n==3)?t[1]*3600+t[2]*60+t[3]:t[1]*60+t[2]; if (s>21600) print $1, s}' | while read pid secs; do case "$PROTECTED" in *" $pid "*) echo "Protecting current session's playwright-mcp: PID $pid (up $((secs/3600))h)"; continue;; esac; echo "Killing stale playwright-mcp: PID $pid (up $((secs/3600))h)"; kill $pid 2>/dev/null; done && echo "Stale MCP cleanup complete"

Then stop dev servers this project started (rule 7). Servers launched in the background are usually re-parented to PID 1, so the orphan step above never sees them. Stop only TCP listeners whose working directory is inside the current **git project root** — other projects and system services are left alone, and the step refuses to run outside a git repo or when the root is `/` or `$HOME`. Browsers (Playwright MCP's Chrome also listens and runs from the project dir) and claude are skipped by **executable name**, playwright-mcp by its arguments — a server whose path merely contains "claude" is still stopped:

PROJ=$(git rev-parse --show-toplevel 2>/dev/null); if [ -z "$PROJ" ] || [ "$PROJ" = "/" ] || [ "$PROJ" = "$HOME" ]; then echo "Skipping project server cleanup: not inside a git project, or its root is / or \$HOME"; else PROJ=$(cd "$PROJ" && pwd -P); lsof -nP -iTCP -sTCP:LISTEN -Fp 2>/dev/null | sed -n "s/^p//p" | sort -u | while read pid; do cwd=$(lsof -a -p "$pid" -d cwd -Fn 2>/dev/null | sed -n "s/^n//p" | head -1); case "$cwd/" in "$PROJ"/*) ;; *) continue;; esac; comm=$(basename "$(ps -o comm= -p "$pid" 2>/dev/null)"); args=$(ps -o args= -p "$pid" 2>/dev/null); case "$comm" in claude|*[Cc]hrome*|*[Cc]hromium*|*headless_shell*) continue;; esac; case "$args" in *playwright-mcp*|*ms-playwright*) continue;; esac; ports=$(lsof -a -p "$pid" -iTCP -sTCP:LISTEN -nP -Fn 2>/dev/null | sed -n "s/^n//p" | tr "\n" " "); echo "Stopping project server: PID $pid [$ports] $(echo "$args" | cut -c1-60)"; kill "$pid" 2>/dev/null; done; fi; echo "Project server cleanup complete"

Then stop the Aside browser sessions started from this project (the `/open-browser` tab and any e2e/publisher sessions left running). Only sessions whose start directory is inside the current git project root are stopped; their tabs close, the Aside app and the user's own tabs are untouched:

PROJ=$(git rev-parse --show-toplevel 2>/dev/null); if [ -n "$PROJ" ] && [ -x "$HOME/.claude/scripts/aside-session.sh" ]; then "$HOME/.claude/scripts/aside-session.sh" stop-under "$PROJ"; fi; echo "Aside session cleanup complete"

Then clean up E2E test artifacts (fail reports and their screenshots) and browser session state:

find . -path "./e2e-results/fail-*" -type f -delete 2>/dev/null; rm -f .claude/browser-session.json 2>/dev/null; echo "E2E artifacts cleanup complete"
