---
name: Skill Description Budget Management
description: When creating new skills, keep description to 1–2 concise lines needed for trigger judgment
type: feedback
---

When creating a new skill, keep the description concise.

**Why:** All skill descriptions are loaded into context at session start and consume budget. Verbose descriptions reduce space available for other areas (reference documents, conversation history).

**How to apply:**
- ✅ DO: Write 1–2 lines containing only the keywords/conditions needed for trigger judgment
- ❌ DON'T: Never put usage examples, detailed behavior explanations, or background context in the description (put those in the skill body instead)
