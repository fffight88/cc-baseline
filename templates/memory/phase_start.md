---
name: Phase Start Checklist
description: Checklist to complete at the start of a phase
type: feedback
---

At the start of a phase, always perform the following steps in order:

1. **Search and load guide documents**
   - Identify the topic of this phase (backend, frontend, design, testing, verification, planning, etc.).
   - Search `{{HOME}}/.claude/memory/` and the project's `.claude/` directory for guide documents related to this topic.
   - If relevant documents are found, read and internalize them before starting work.

2. **Re-confirm the task list**
   - Re-check the task list for this phase from TaskList or the plan.
   - Clearly understand the scope and completion criteria of each task before starting work.
