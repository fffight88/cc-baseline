What is OpenCode?

OpenCode is an open source agent that helps you write and run code directly from the terminal, desktop app or IDE.

[+]LSP enabledAutomatically loads the right LSPs for the LLM
[+]Multi-sessionStart multiple agents in parallel on the same project
[+]Share linksShare a link to any session for reference or to debug
[+]Any model75+ LLM providers through Models.dev, including local models
[+]Any editorTerminal UI, desktop app, and VS Code / Zed extensions
[-]No lock-inBring your own keys or sign in with an existing subscription

Built for privacy first

OpenCode does not store any of your code or context data. It runs locally, talks directly to the provider you choose, and can operate in environments with no outbound access beyond your model endpoint.
