Install the JavaScript SDK

Add posthog-js to your app and initialize it with your project API key. Autocapture starts tracking clicks and pageviews right away — see autocapture docs.

// npm install posthog-js
import posthog from 'posthog-js'

posthog.init('phc_3kF9xQ2mVb7', {
  api_host: 'https://us.i.posthog.com',
  person_profiles: 'identified_only',
  session_recording: { sampleRate: 0.5 }
})

posthog.capture('signed_up', { plan: 'free' })
💡 Tip: Use a reverse proxy so ad blockers don't drop your events.
✅ Success: Events show up in the Activity tab within seconds.
⚠️ Warning: Never expose your personal API key in client-side code.
