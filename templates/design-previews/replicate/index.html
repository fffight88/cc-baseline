How it works

You don't need to understand machine learning. Find a model, call it from your code, and pay only for the compute you use.

1

Pick a model

Browse thousands of models published by the community and the labs that built them.

2

Call the API

Every model has a production-ready HTTP API, plus clients for Python and Node.js.

3

Scale automatically

We spin up GPUs when traffic arrives and scale to zero when it doesn't.

PythonNode.jscURLHTTP
import replicate

output = replicate.run(
    "black-forest-labs/flux-1.1-pro",
    input={
        "prompt": "a lighthouse at dusk, 35mm film",
        "aspect_ratio": "3:2",
        "output_format": "webp",
    },
)

# Save the generated image
with open("lighthouse.webp", "wb") as f:
    f.write(output.read())
