Everything you need

A framework that stays out of your way

Typed primitives for every layer of an agent — compose them, swap providers, and keep full control of your code.

Agents & sub-agents

Supervisor agents delegate to specialists with shared context and typed handoffs.

new Agent({ subAgents })

Workflows

Declarative steps with suspend, resume and human-in-the-loop approval.

createWorkflowChain()

Memory

Conversation, working and semantic memory on LibSQL, Postgres or Supabase.

memory: new LibSQLMemory()

Tools & MCP

Zod-typed tools and native Model Context Protocol servers in one line.

createTool({ parameters })

Guardrails

Validate inputs and outputs, redact PII and block unsafe tool calls.

guardrails: [piiFilter]
