# v1.2 Plan — README Split + Project-Local Install Mode

## Meta
- **Security Impact:** Yes — new PreToolUse hook to protect `./.claude/memory/`; install/uninstall code now handles cwd-based paths; new `.mcp.json` write target needs path-normalization and symlink-traversal review.
- **Code Quality Impact:** Yes — `install.js`/`uninstall.js`/`doctor.js` are refactored to parameterize `CLAUDE_DIR`; new manifest branches and templates are added; regression risk in the existing 39 tests.
- **Reason:** PreToolUse path-policy hook, hooks merge logic, manifest loader, and test coverage are all affected.

## ⚡ Key Rules Summary

| ✅ DO | ❌ DON'T |
|---|---|
| Split 5 README sections into `docs/`; mirror to `docs/ko/` | Cut sections out without leaving a 1–3 line summary + link |
| Trigger project mode with explicit `--project` flag | Auto-detect via cwd `.claude/` (Q3 rejected) |
| Project mode **overlays** global (separate hook entries, separate MEMORY index) | Overwrite or ignore global rules |
| Add a new PreToolUse hook for `./.claude/memory/` protection | Widen the global hook's regex to catch both |
| Parameterize `CLAUDE_DIR` so global + project paths share core logic | Duplicate install.js into install-project.js |
| Keep existing 39 tests green; add new tests for project mode | Modify existing test signatures |
| Use `npx -y @playwright/mcp@latest` in `.mcp.json` for portability | Bake absolute paths like `{{HOME}}/.npm-global/bin/playwright-mcp` |
| Always attempt scanner + Playwright MCP install (skip if present) | Skip scanners in project mode (agents would not run) |

## Phase 2 — Project-Local Install Mode

### 2.1 CLI Extensions (`bin/cli.js`)

```
--project                Install into ./.claude/ (project-local mode)
--project --doctor       Verify project install
--project --uninstall    Remove from ./.claude/
--project --dry-run      Preview only
```

Compatibility matrix:
- `--project` + `--skip-scanners` → OK (scanners are machine-global anyway)
- `--project` + `--purge` → deletes `./.claude/.cc-baseline-backup/`

### 2.2 Core Refactor — Parameterize `TARGET_DIR`

Replace the module-level `CLAUDE_DIR` constant in `src/install.js`, `src/uninstall.js`, `src/doctor.js` with a `resolveTarget(opts)` helper:

```js
function resolveTarget(opts) {
  if (opts.project) {
    const cwd = process.cwd();
    return {
      mode: 'project',
      claudeDir: path.join(cwd, '.claude'),
      mcpJsonPath: path.join(cwd, '.mcp.json'),
      backupRoot: path.join(cwd, '.claude', '.cc-baseline-backup'),
      installLog: path.join(cwd, '.claude', '.cc-baseline-install.log'),
    };
  }
  return {
    mode: 'global',
    claudeDir: path.join(HOME, '.claude'),
    mcpJsonPath: path.join(HOME, '.claude.json'),
    backupRoot: path.join(HOME, '.claude', '.cc-baseline-backup'),
    installLog: path.join(HOME, '.claude', '.cc-baseline-install.log'),
  };
}
```

- ✅ DO: thread `target` as a parameter object
- ❌ DON'T: re-read `process.cwd()` inside helpers

### 2.3 Manifest Behavior Matrix

| Item | Global mode | Project mode |
|---|---|---|
| `CLAUDE.md` merge | `~/.claude/CLAUDE.md` | `./.claude/CLAUDE.md` |
| `settings-hooks` source | `templates/settings-hooks.json` | `templates/settings-hooks.project.json` (new) |

| `terminal-notifier` (macOS) | Install if missing | Install if missing |
| memory / agents / commands / scripts | `~/.claude/...` | `./.claude/...` |

### 2.4 New Template Files

#### `templates/settings-hooks.project.json`

- SessionStart hook loads `./.claude/memory/MEMORY.md` (cwd-relative, executed from project root)
- `_ccBaselineId` values are prefixed with `project-` (e.g. `project-session-start-load-rules`) to avoid colliding with global IDs in the same JSON file (Claude Code merges global + project settings)
- PreToolUse protection hook target: `./.claude/memory/` (normalized via `os.path.realpath`)
- E2E guide hook is **omitted** — the global hook already covers it

### 2.5 New PreToolUse Protection Hook (security-critical)

```python
protected = os.path.realpath(os.path.join(os.getcwd(), '.claude', 'memory'))
if real_path.startswith(protected + os.sep) or real_path == protected:
    deny
```

- ✅ DO: normalize via `realpath` to defeat symlinks / `../` traversal
- ❌ DON'T: simple `startswith('./.claude/memory/')` string match
